# 开源范围与素材边界

仅发布本仓库的通用 BlendPlay 插件源码、代码生成的人形与基础动画、安装／打包工具、通用脚本示例和文档。

明确不包含，也未授权：DOORS 完整游戏、房间模板、关卡排列、怪物造型与动画、专用玩法／谜题／追逐逻辑、模型、贴图、音乐、音效、截图、试玩录像、用户存档或任何游戏 `.blend` 文件。

引擎示例只由插件内的通用几何体生成器创建，不从任何游戏工程读取数据。启动模板在安装时从全新 Blender 场景生成；仓库不收录既有二进制工程。

发布采用文件白名单。构建器只打包 `blendplay/` 中声明的 Python 模块、README、LICENSE；不递归复制桌面或原游戏目录。不要把原工作目录、历史版本、备份或工作日志直接推送到此仓库。

项目不附带第三方角色、字体、PBR素材或音频库。Blender本身不打包在此项目中；它有自己的许可及第三方依赖声明。
