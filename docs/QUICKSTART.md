# 快速开始

1. 安装并启用插件后，从BlendPlay面板创建游戏项目。通用示例由代码生成平台、玩家、镜头和金币。
2. “游戏 IDE”中选中模型，打开它的组件脚本。新模型不会被强制添加脚本；需要时选择添加脚本。
3. 使用“新建代码”建立独立文件，可加入全局脚本列表，或绑定对象。
4. 普通组件模板继承 `Behaviour`，组件内使用 `self.object` 和 `self.game`。全局入口使用 `start(game)`、`update(game, dt)`、`stop(game)`。
5. 修改后保存 `.blend`；脚本文本作为Blender数据保存在工程内。重要工程也应另存备份。
6. 使用“运行整个游戏”测试，Esc回到编辑状态。脚本异常显示在游戏设置和“游戏错误.log”文本中。

复制／粘贴使用文本编辑器的原生操作。对象名称必须和代码中的名称完全一致；名称含中文也可以使用。

`.blend` 文件需要已安装且启用此插件才能运行游戏。安装器附带的Game启动模板是可选功能；插件本身也能在普通工程里使用。
